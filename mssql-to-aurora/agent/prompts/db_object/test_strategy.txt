## テスト網羅基準
各 DB オブジェクトに対し、以下のカテゴリを網羅すること:

- 正常系 (代表入力で期待通り): 最低3ケース
- 境界値 (NULL, 空文字, ゼロ, 最大値, 負値): 最低3ケース
- 例外系 (不正入力で適切なエラー): 最低2ケース
- トランザクション (該当時のロールバック動作): 該当時1ケース
- 副作用 (INSERT/UPDATE/DELETE の件数・内容): 該当時2ケース

## テストの構造
各 *_test.sql は次のセクションを含むこと:

  1. SETUP    - テストデータ準備、一時テーブル作成
  2. EXEC     - 対象オブジェクトを複数パターンで実行
  3. ASSERT   - 結果を SELECT で出力 (後段で比較できる形)
  4. CLEANUP  - 一時テーブル DROP、副作用ロールバック

## アサーション形式
- 結果セットは SELECT 文で表形式に出力する
- 単一値は `SELECT result = ... AS result` の形で出力する
- エラー期待のテストは TRY-CATCH (T-SQL) / BEGIN-EXCEPTION (PL/pgSQL) でエラーメッセージを文字列として出力する

## 自動許容差分
以下は「差分なし」とみなす:
- DATETIME の `.000` と `.000000` のサフィックス
- 末尾空白のあり/なし (CHAR(n) 由来)
- 浮動小数の 6桁以下の丸め誤差
- ORDER BY 未指定クエリの順序差 (両方ソート後比較)
