   ----------------
   Difference: PostgreSQL identifiers are case-insensitive by default
   
   Impact:
   - Table name comparison uses lower() for consistency
   - If tables have mixed-case names, they must be quoted in DDL
   
   Example:
   - T-SQL: CREATE TABLE MyTable (...)  → accessible as MyTable, mytable, MYTABLE
   - PG: CREATE TABLE MyTable (...)     → stored as mytable
   - PG: CREATE TABLE "MyTable" (...)   → stored as MyTable (case-preserved)
   
   Current implementation: Uses lower() for comparison
   Enhancement: Could add case-sensitive mode if needed
