KEY CONVERSION CHANGES
============================================================================

1. PIVOT OPERATOR → CASE EXPRESSIONS
   ────────────────────────────────────
   T-SQL:
     PIVOT (COUNT(employee_id) FOR department_name IN ([Dept1], [Dept2], ...))
   
   PostgreSQL:
     SUM(CASE WHEN department_name = 'Dept1' THEN 1 ELSE 0 END) AS "Dept1",
     SUM(CASE WHEN department_name = 'Dept2' THEN 1 ELSE 0 END) AS "Dept2",
     ...
     GROUP BY job_title
   
   Reason: PostgreSQL does not have native PIVOT operator
   Alternative: tablefunc.crosstab() requires predefined columns
   Chosen: Dynamic CASE expressions for flexibility

2. FOR XML PATH → FOR LOOP
   ────────────────────────────────────
   T-SQL:
     SELECT @columns = STUFF((
         SELECT DISTINCT ',' + QUOTENAME(d.department_name)
         FROM ...
         FOR XML PATH(''), TYPE
     ).value('.', 'NVARCHAR(MAX)'), 1, 1, '');
   
   PostgreSQL:
     FOR v_dept_name IN (
         SELECT DISTINCT d.department_name FROM ... ORDER BY ...
     ) LOOP
         v_pivot_columns := v_pivot_columns || 
             'SUM(CASE WHEN department_name = ' || quote_literal(v_dept_name) || 
             ' THEN 1 ELSE 0 END) AS ' || quote_ident(v_dept_name);
     END LOOP;
   
   Reason: PostgreSQL does not support FOR XML PATH
   Alternative: string_agg() for simple concatenation
   Chosen: FOR loop for complex expression building

3. QUOTENAME() → quote_ident()
   ────────────────────────────────────
   T-SQL:    QUOTENAME(department_name)
   PostgreSQL: quote_ident(department_name)
   
   Both functions quote identifiers for safe use in dynamic SQL

4. sp_executesql → EXECUTE ... USING
   ────────────────────────────────────
   T-SQL:
     EXEC sp_executesql @sql, 
         N'@as_of_date DATETIME, @include_inactive BIT',
         @as_of_date = @as_of_date,
         @include_inactive = @include_inactive;
   
   PostgreSQL:
     EXECUTE v_sql USING v_as_of_date, p_include_inactive;
   
   Parameter placeholders: @param → $1, $2, ...

5. GETDATE() → now()
   ────────────────────────────────────
   T-SQL:    GETDATE()
   PostgreSQL: now()
   
   Both return current timestamp

6. BIT → BOOLEAN
   ────────────────────────────────────
   T-SQL:    @include_inactive BIT = 0
   PostgreSQL: p_include_inactive BOOLEAN DEFAULT FALSE
   
   T-SQL:    @include_inactive = 1
   PostgreSQL: p_include_inactive = TRUE

7. ISNULL() → COALESCE()
   ────────────────────────────────────
   T-SQL:    ISNULL(e.job_title, 'Unknown')
   PostgreSQL: COALESCE(e.job_title, 'Unknown')
   
   Functionally equivalent

8. CROSS APPLY → Direct Arithmetic
   ────────────────────────────────────
   T-SQL:
     CROSS APPLY (
         SELECT [Dept1] + [Dept2] + ... AS total_count
     ) AS TotalCalc
   
   PostgreSQL:
     COALESCE("Dept1", 0) + COALESCE("Dept2", 0) + ... AS total_count
   
   Simpler and more efficient

9. SET NOCOUNT ON

   T-SQL:    SET NOCOUNT ON;
   PostgreSQL: (removed - not needed)
   
   PostgreSQL doesn't send row count messages by default

DYNAMIC SQL CONSTRUCTION
============================================================================

The procedure builds a dynamic SQL query with the following structure:

1. Loop through distinct departments (ordered)
2. For each department, generate:
   - CASE expression: SUM(CASE WHEN department_name = 'X' THEN 1 ELSE 0 END) AS "X"
   - Total expression component: COALESCE("X", 0)
3. Combine into final query:
   SELECT job_title, [dept columns], [total] FROM (...) GROUP BY job_title

Example generated SQL:
  SELECT 
      job_title,
      SUM(CASE WHEN department_name = 'Engineering' THEN 1 ELSE 0 END) AS "Engineering",
      SUM(CASE WHEN department_name = 'Sales' THEN 1 ELSE 0 END) AS "Sales",
      COALESCE("Engineering", 0) + COALESCE("Sales", 0) AS total_count
  FROM (
      SELECT 
          COALESCE(e.job_title, 'Unknown') AS job_title,
          d.department_name,
          e.employee_id
      FROM public.employees e
      LEFT JOIN public.departments d ON e.department_id = d.department_id
      WHERE e.hire_date <= $1
        AND ($2 = TRUE OR e.status = 'Active')
  ) AS source_data
  GROUP BY job_title
  ORDER BY job_title
