Purpose: INSERT or UPDATE department records (UPSERT pattern)

  Input:

    - @department_name NVARCHAR(100) (required)
    - @location NVARCHAR(100) (optional)
    - @manager_id INT (optional, FK to employees)
  
  Output:
    - @result_id INT (returns department_id)
    - @operation NVARCHAR(10) (returns 'INSERT' or 'UPDATE')

Dependencies:
  - dbo.departments (table) - target table for UPSERT
  - dbo.employees (table) - for manager_id FK validation

Business Logic:
  1. Validates required fields (@department_name)
  2. Trims whitespace from department_name
  3. Validates manager_id exists in employees table
  4. Checks for duplicate department_name on INSERT
  5. Performs INSERT if department_id is NULL or doesn't exist
  6. Performs UPDATE if department_id exists
  7. Sets created_date on INSERT, modified_date on UPDATE
  8. Returns result_id and operation type
