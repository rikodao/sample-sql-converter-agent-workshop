BEHAVIORAL DIFFERENCES
============================================================================

1. RESULT SETS
   - T-SQL: Procedures can return result sets via SELECT
   - PostgreSQL: Procedures cannot return result sets
   - Solution: Use INOUT parameters or create a FUNCTION RETURNS TABLE

2. TRANSACTIONS
   - T-SQL: Explicit BEGIN TRAN / COMMIT / ROLLBACK
   - PostgreSQL: Implicit in procedures, automatic rollback on exception

3. TEMP TABLE CLEANUP
   - T-SQL: Manual DROP or automatic on connection close
   - PostgreSQL: ON COMMIT DROP for automatic cleanup per transaction

4. ERROR INFORMATION
   - T-SQL: Rich error info (severity, state, line, procedure)
   - PostgreSQL: Limited to SQLSTATE and SQLERRM

5. BOOLEAN TYPE
   - T-SQL: BIT type (0/1)
   - PostgreSQL: BOOLEAN type (true/false)
   - Conversion: Cast BIT to BOOLEAN where needed
