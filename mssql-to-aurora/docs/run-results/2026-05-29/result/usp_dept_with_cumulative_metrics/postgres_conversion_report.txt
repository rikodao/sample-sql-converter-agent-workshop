     - T-SQL: 'A' + NULL = NULL (ANSI behavior with CONCAT_NULL_YIELDS_NULL ON)
     - PG: 'A' || NULL = NULL (same behavior)
     - Impact: NONE - both treat NULL consistently
  
  3. Error Messages:
     - T-SQL: "Start date cannot be after end date" (custom message)
     - PG: Same message, but error code differs (SQLSTATE P0001 vs MSSQL 50000)
     - Impact: Error handling code may need adjustment

     - T-SQL: EXEC dbo.usp_dept_with_cumulative_metrics @start_date='2023-01-01'
     - PG: SELECT * FROM public.usp_dept_with_cumulative_metrics('2023-01-01'::timestamp)
     - Impact: Application code must be updated

  5. Transaction Behavior:
