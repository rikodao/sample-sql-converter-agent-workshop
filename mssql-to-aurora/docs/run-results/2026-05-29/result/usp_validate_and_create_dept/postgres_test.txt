SEMANTIC DIFFERENCES (ACCEPTABLE)
============================================================================

The following differences between MSSQL and PostgreSQL are expected
and should be treated as SEMANTIC MATCH (not MISMATCH):

1. Timestamp Precision:
   - MSSQL: DATETIME (milliseconds, 3 digits)
   - PostgreSQL: TIMESTAMP (microseconds, 6 digits)
   - Example: 2026-05-29 10:00:00.123 vs 2026-05-29 10:00:00.123000

2. Boolean Representation:
   - MSSQL: BIT (0/1)
   - PostgreSQL: BOOLEAN (FALSE/TRUE or f/t)
   - Example: is_active=1 vs is_active=TRUE

3. NULL Representation:
   - MSSQL: NULL (no quotes)
   - PostgreSQL: NULL (no quotes) or empty string in some contexts
   - Both should be treated as NULL

4. Error Message Formatting:
   - Minor differences in spacing, punctuation acceptable
   - Core message content must match

5. Numeric Precision:
   - MSSQL: INT (4 bytes)
   - PostgreSQL: INTEGER (4 bytes)
   - Should be identical for values in test range
