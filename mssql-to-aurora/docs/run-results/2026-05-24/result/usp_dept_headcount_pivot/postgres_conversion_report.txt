   T-SQL (Original):
   ```sql

       SELECT
           d.name AS department_name,

           e.employee_id
       FROM dbo.departments d
       LEFT JOIN dbo.employees e ON d.department_id = e.department_id
   ```

   ```sql
       d.name AS department_name,
       COUNT(CASE WHEN e.is_active = TRUE THEN e.employee_id END) AS "Active",

   FROM public.departments d
   ```
