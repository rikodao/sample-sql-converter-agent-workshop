============= TEST CASE 10: Verify sorting by department name =============
DESCRIPTION: Confirm results are ordered alphabetically by department name
SETUP: Using accumulated test data

EXECUTION:
SELECT department_name, Active, Inactive
FROM (
    SELECT
        d.name AS department_name,
        CASE WHEN e.is_active = 1 THEN 'Active' ELSE 'Inactive' END AS status,
        e.employee_id
    FROM dbo.departments d
    LEFT JOIN dbo.employees e ON d.department_id = e.department_id
) src
PIVOT (
    COUNT(employee_id) FOR status IN ([Active], [Inactive])
) p
ORDER BY department_name;

RESULTS:

4. HR

6. R&D

9. Test Active Only

11. Test Inactive Only

ASSERT: TC10 - Results correctly sorted by department_name
