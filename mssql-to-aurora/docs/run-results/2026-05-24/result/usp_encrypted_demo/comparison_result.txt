================================================================================

WITH ENCRYPTION in SQL Server:
- Proprietary encryption algorithm that obfuscates object definitions
- Encryption is one-way (no official decryption method)
- Designed to protect intellectual property, not for security
- Prevents all metadata-based extraction methods
- Incompatible with migration to other database platforms
