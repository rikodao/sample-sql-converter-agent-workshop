STATUS: ⚠ SEMANTIC DIFFERENCE
- PostgreSQL is case-sensitive by default (2 rows exist)
- MSSQL is case-insensitive by default (1 row exists)
- This is a known collation difference between MSSQL and PostgreSQL
- To achieve MSSQL behavior, need to use CITEXT type or case-insensitive collation
