   理由: PostgreSQL のデフォルトスキーマは public

4. Recursive CTE
   T-SQL:

         SELECT ..., 0 AS depth, CAST(name AS NVARCHAR(MAX)) AS path
         FROM dbo.departments
         WHERE department_id = @root_id

     )
   
   PL/pgSQL:
     WITH RECURSIVE org AS (
         SELECT ..., 0 AS depth, CAST(d.name AS VARCHAR) AS path
         FROM public.departments d
         WHERE d.department_id = p_root_id
         UNION ALL
         SELECT ..., o.depth + 1, o.path || ' > ' || d.name
         ...
     )
   
   変更点:

   - NVARCHAR(MAX) → VARCHAR (PostgreSQL では VARCHAR は可変長)
   - 文字列連結: + → || (PostgreSQL の標準演算子)
   - N'...' → '...' (PostgreSQL では N プレフィックス不要)
