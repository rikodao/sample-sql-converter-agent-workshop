All test cases were blocked due to a runtime limitation in Babelfish.

## ERROR DETAILS

### Error Code: 42000
### Error Message:
[42000] [Microsoft][ODBC Driver 18 for SQL Server][SQL Server]procedure parameter "@json_out" is an output parameter but corresponding argument is not writable (33557097)

### Failed Test Case Example:
```sql
DECLARE @json_result NVARCHAR(MAX);
EXEC dbo.usp_employee_json @employee_id = 1, @json_out = @json_result OUTPUT;
SELECT @json_result AS json_output;
```

## ROOT CAUSE

Babelfish's TDS (Tabular Data Stream) protocol implementation does not fully support OUTPUT parameter binding when stored procedures are called from external clients. While the procedure definition is accepted during DDL deployment, the runtime execution fails when attempting to bind OUTPUT parameters.

## MIGRATION IMPLICATIONS

### Impact: HIGH
This limitation affects:
1. All stored procedures using OUTPUT parameters
2. Application code that calls these procedures
3. Integration patterns relying on OUTPUT parameter values

### Required Changes:
1. **Procedure Refactoring**: Convert OUTPUT parameters to result sets
2. **Application Code Changes**: Modify calling code to read result sets instead of OUTPUT parameters
3. **Testing**: Comprehensive testing of refactored procedures

### Example Refactoring:
**Original (SQL Server):**
