- Applies a percentage-based salary raise to active employees with minimum years of service
- Uses CURSOR to iterate through eligible employees
- Parameters:

  * @min_years_of_service INT = 3 (default)
- Eligibility: is_active = 1, hire_date >= @min_years_of_service years ago, has current salary
- For each eligible employee:
  1. Calculates new salary = current salary * (1 + @raise_pct / 100.0)
  2. Updates existing salary record: sets effective_to = today - 1 day
  3. Inserts new salary record with new amount and effective_from = today
- Uses OUTER APPLY to get most recent salary (TOP 1 ORDER BY effective_from DESC)
