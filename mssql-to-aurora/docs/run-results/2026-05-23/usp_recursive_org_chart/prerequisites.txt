================================================================================
オブジェクト概要
================================================================================
このストアドプロシージャは再帰CTE (Common Table Expression) を使用して、
指定されたルート部門から始まる組織階層を取得します。

パラメータ:
  @root_id INT - ルート部門のID

出力:
  - department_id: 部門ID
  - name: 部門名
  - depth: 階層の深さ (0がルート)
  - path: ルートからの経路 (例: "本社 > 営業部 > 東京営業所")

特徴:
  - 再帰CTEを使用した階層構造の展開
  - 深さ情報の計算
  - パス文字列の生成 (NVARCHAR(MAX))
  - パスでソートして出力

================================================================================
検証ポイント
================================================================================
1. 正常系: 複数階層の組織構造を正しく展開できるか
2. 境界値: ルートのみ (子なし)、存在しないID、NULL入力
3. 例外系: 循環参照がある場合の動作 (SQL Serverは最大再帰回数でエラー)
4. パス生成: NVARCHAR(MAX)の連結が正しく動作するか
5. ソート順: パスによるソートが正しく機能するか
