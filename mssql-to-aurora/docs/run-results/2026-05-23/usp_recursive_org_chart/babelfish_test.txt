Migration Considerations
================================================================================

1. ✓ 再帰CTE互換性:
   - PostgreSQL の再帰CTEは正常動作
   - WITH 句の構文は互換性あり

2. ✓ NVARCHAR(MAX) の扱い:
   - TEXT 型へのマッピングが正常動作
   - 文字列連結演算子 (+) も互換性あり

3. ✓ ORDER BY の動作:
   - 文字列ソート順序は同等
   - 日本語文字を含む場合も正常

4. ✓ NULL比較の動作:
   - WHERE column = NULL の動作は標準SQLと同じ (常にFALSE)
   - 両環境で同じ動作

5. ⚠️ MAXRECURSION オプション:
   - SQL Server: OPTION (MAXRECURSION n) でデフォルト100、最大32767
   - Babelfish/PostgreSQL: このオプションは未サポート
   - 対策: アプリケーションレベルでの深度チェック、または CTE 内での深度制限

6. 推奨事項:
   - 循環参照を防ぐため、CTE に深度制限を追加:
     ```sql
     WHERE o.depth < 100  -- 再帰メンバーに追加
     ```
   - または訪問済みノードを配列で追跡:
     ```sql
     WHERE d.department_id <> ALL(o.visited_ids)
     ```
