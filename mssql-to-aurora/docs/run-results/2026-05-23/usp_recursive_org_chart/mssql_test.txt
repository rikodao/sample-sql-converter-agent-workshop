Migration Considerations
================================================================================

1. Babelfish/PostgreSQL での再帰CTE互換性:
   - PostgreSQL は再帰CTEをサポート (WITH RECURSIVE)
   - MAXRECURSION オプションの扱いに注意

2. NVARCHAR(MAX) の扱い:
   - PostgreSQL では TEXT 型にマッピング
   - 文字列連結演算子の互換性確認が必要

3. ORDER BY の動作:
   - 文字列ソート順序 (collation) の違いに注意
   - 特に日本語文字を含む場合

4. NULL比較の動作:
   - WHERE column = NULL の動作は標準SQLと同じ (常にFALSE)
   - 両環境で同じ動作が期待できる
